# 순천 여행 공동 경비 기록

사진첩 기능은 제거했습니다. 이 폴더는 공동 경비만 관리합니다.

- `data.json`: 승인된 기본 경비 11개와 사전 결제 합계입니다. 이름·사진·댓글은 포함하지 않습니다.
- `adapter.js`: 기본 경비와 이슈에 등록한 공금 상태를 읽습니다.
- `client.js`: 사이트의 경비 입력과 GitHub 등록 화면을 연결합니다.
- `schema.json`: 빈 데이터 형식 예시이며 운영 데이터가 아닙니다.

사전 결제는 1인 112,400원·5인 562,000원입니다. 현장 공금 1인 200,000원·5인 1,000,000원에서 사전 결제액을 차감하지 않습니다. 현장 항목은 예상 예산으로, 실제 결제 완료를 뜻하지 않습니다.

## 변경 저장

1. 사이트에서 인원수나 포함할 경비를 변경합니다.
2. `GitHub에 변경 등록`을 누릅니다.
3. GitHub에 로그인하고 열린 등록 화면에서 이슈 등록을 확정합니다.
4. 사이트로 돌아와 `다시 불러오기`를 누릅니다. 다른 방문자도 같은 기록을 불러옵니다.

새 경비는 사이트의 `추가` 버튼으로 입력한 뒤 동일하게 GitHub에서 확정합니다. 단순히 사이트 버튼을 누른 것만으로 저장이 완료되지는 않습니다.

기록은 공개 GitHub 저장소에 저장됩니다. 브라우저 저장소와 별개이며 다른 기기에서 조회할 수 있습니다. 체크와 인원 변경은 등록 전까지 계산 초안입니다.

유효한 열린 이슈를 생성 순서대로 적용합니다. `expense`는 경비 추가, `budget`은 인원수와 경비 목록 전체 상태입니다. 나중에 생성된 공금 상태가 앞선 상태를 대체합니다. 이슈의 JSON 데이터 블록을 유지하세요. 이슈를 닫으면 공동 조회에서 제외됩니다.

인증 토큰은 소스나 브라우저에 넣지 않습니다. 사이트 안에서 바로 자동 저장하려면 별도의 서버 인증 연결이 필요합니다.
