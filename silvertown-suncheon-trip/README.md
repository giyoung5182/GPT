# GitHub 공동 기록 연결

이 폴더에는 개인 여행 데이터가 없는 연결 코드와 빈 데이터 형식만 있습니다.

- `adapter.js`: 공개 저장소의 기본 JSON과 GitHub 이슈를 읽어 공동 상태를 구성합니다.
- `schema.json`: 실제 기록이 포함되지 않은 데이터 형식 예시입니다. 운영 데이터가 아닙니다.

등록 과정은 사이트 입력 → GitHub 이슈 등록 화면 → 사용자의 등록 확정 → 사이트에서 다시 불러오기입니다. 등록하는 사람에게 GitHub 로그인이 필요합니다. 사이트에서 버튼을 누르는 것만으로 저장이 완료되지는 않습니다.

사진은 GitHub 이슈 등록 화면에 첨부합니다. 댓글과 좋아요는 해당 이슈 화면에서 남깁니다. 공개 저장소에 올린 기록은 누구나 볼 수 있습니다.

지출은 `expense`, 공금 상태는 `budget`, 사진·후기는 `album` 형식을 사용합니다. 유효한 열린 이슈만 적용하며 생성 순서대로 반영합니다. 공금 상태 등록은 그 시점의 인원과 지출 목록 전체를 저장합니다. 여러 사람이 등록하면 나중에 생성된 공금 상태가 앞선 상태를 대체합니다.

인증 토큰을 소스 코드나 브라우저에 넣지 않습니다. 직접 자동 저장을 하려면 별도의 서버 인증 연결이 필요합니다.

운영 데이터 업로드와 사이트 적용은 아직 완료되지 않았습니다.
